# Others

Miscellaneous CAD that did not belong in a dedicated repository: older robots, early prototypes and backups.

## Contents
- `ninja/` — CAD of the **Ninja** robot, with its `piece util`, gripper and map files
- `eurobot test 1.0/` — copy of the test robot (see the [eurobot-test-1.0](https://github.com/Eurobot-2026-CAD-departement/eurobot-test-1.0) repo)
- `prototype flipper/`, `prototype hatem/`, `prototype mahdi/` — small prototype parts
- `3d printing pami/` — print files for the PAMI
- `backup/` — backup files
- Assorted vendor parts (e.g. ball screw, Airtec valve)

---

Part of the CAD work of the **Aerobotix (INSAT, Tunisia) Eurobot 2026 team** — see the [organization](https://github.com/Eurobot-2026-CAD-departement) for the other repositories. Files are mainly SolidWorks (`.SLDPRT` / `.SLDASM`) with STEP / STL / DXF exports. Released under the [MIT License](LICENSE). Questions about anything unclear? Contact a team member.
